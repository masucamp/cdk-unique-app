# AWS マニアックサービス活用アプリケーション - 実装サマリー

## プロジェクト概要

このプロジェクトでは、AWSの一般的ではない「マニアックな」サービスを組み合わせて、医療記録音声アシスタントアプリケーションを構築しました。このアプリケーションは、医療テキストから重要な情報を抽出し、それを自然な音声に変換することで、医療従事者の業務効率化をサポートします。

## 選定したAWSマニアックサービス

1. **AWS Comprehend Medical**
   - 医療特化型の自然言語処理サービス
   - 一般的なComprehendよりも専門的で利用頻度が低い
   - 医療記録から診断、薬剤、処置などの情報を高精度で抽出可能

2. **AWS Polly Neural Text-to-Speech**
   - 自然な音声合成サービス
   - 特に神経ネットワークベースの音声合成は比較的新しく、マニアックな領域
   - 長時間聞いても疲れにくい自然な音声を生成

3. **AWS Step Functions**
   - サーバーレスワークフロー管理サービス
   - 複雑な処理フローを視覚的に設計・管理できる
   - エラーハンドリングや再試行ロジックを容易に実装可能

## 実装内容

1. **CDKスタック**
   - 入力用と出力用のS3バケット
   - 3つのLambda関数（トリガー、テキスト分析、音声合成）
   - Step Functionsワークフロー
   - 必要なIAMロールとポリシー

2. **Lambda関数**
   - `trigger-workflow`: S3イベントからStep Functionsを起動
   - `analyze-text`: Comprehend Medicalを使用して医療テキストを分析
   - `text-to-speech`: Pollyを使用してテキストを音声に変換

3. **テスト**
   - CDKスタックのユニットテスト
   - サンプル医療テキストファイル

4. **ドキュメント**
   - README（概要、デプロイ手順、使用方法、評価レポート）
   - アーキテクチャ図
   - 詳細なアーキテクチャドキュメント
