# 医療記録音声アシスタント - アーキテクチャ詳細

## アーキテクチャ概要

このアプリケーションは、AWS Comprehend Medical、AWS Polly、AWS Step Functionsを組み合わせて、医療テキストから重要な情報を抽出し、それを音声に変換するサーバーレスアーキテクチャを実現しています。

```
+----------------+     +-------------------+     +------------------------+
|                |     |                   |     |                        |
| S3 Input       |     | Step Functions    |     | Lambda +               |
| Bucket         +---->+ Workflow          +---->+ Comprehend Medical     |
| (Text Files)   |     | (Orchestration)   |     | (Medical Text Analysis)|
|                |     |                   |     |                        |
+----------------+     +-------------------+     +------------------------+
                                                            |
                                                            v
                       +----------------+     +------------------------+
                       |                |     |                        |
                       | S3 Output      |     | Lambda +               |
                       | Bucket         +<----+ Polly                  |
                       | (Audio Files)  |     | (Text-to-Speech)       |
                       |                |     |                        |
                       +----------------+     +------------------------+
```

## コンポーネント詳細

### 1. S3 入力バケット
- 医療テキストファイルのアップロード先
- ファイルがアップロードされると、Lambda関数を通じてStep Functionsワークフローを起動

### 2. Step Functions ワークフロー
- 全体のプロセスを調整
- 各ステップ間のデータ受け渡しを管理
- エラーハンドリングと再試行ロジックを提供

### 3. Comprehend Medical 分析 Lambda
- S3から医療テキストを取得
- AWS Comprehend Medicalを使用して医療エンティティ（診断、薬剤、処置など）を抽出
- 抽出された情報を構造化して要約を生成

### 4. Polly 音声合成 Lambda
- 生成された医療情報要約を受け取る
- AWS Polly Neural Voiceを使用して自然な音声に変換
- 生成された音声ファイルをS3出力バケットに保存

### 5. S3 出力バケット
- 生成された音声ファイルの保存先
- ユーザーはここから音声ファイルをダウンロード可能

## データフロー

1. ユーザーが医療テキストファイルをS3入力バケットにアップロード
2. S3イベント通知がトリガーLambda関数を起動
3. トリガーLambda関数がStep Functionsワークフローを開始
4. Step FunctionsがComprehend Medical分析Lambda関数を呼び出し
5. Comprehend Medical分析Lambda関数が医療テキストを分析し、重要な医療情報を抽出
6. 抽出された情報がStep Functionsを通じてPolly音声合成Lambda関数に渡される
7. Polly音声合成Lambda関数が医療情報要約を音声に変換
8. 生成された音声ファイルがS3出力バケットに保存される
9. ユーザーが音声ファイルにアクセス可能になる

## セキュリティ考慮事項

- IAMロールとポリシーによる最小権限の原則の適用
- S3バケットへのアクセス制限
- 医療データの機密性を考慮した設計
- 将来的にはKMSによる暗号化の実装を検討
